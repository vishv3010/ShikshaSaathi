# AI usage log

Which AI tools were used, for what, and who checked or decided what. Updated as the work happens, not at the end.

## In short

- **Claude Code (Claude Opus 5.5)** was the main build partner: research, design discussion, code, tests and docs. Its work was checked, not trusted: tests use values worked out by hand from the data, 13 planted bugs must all be caught, an independent code review found 10 more bugs, and the app was run and looked at in a phone-size browser.
- **Claude Code's skills and web search** for an independent code review, a design critique, an accessibility audit, the page's visual design and chart colours (frontend-design and dataviz skills, with a colour-blindness validator), for launching and driving the app, and for facts (UDISE+ school types, RTE teacher norms, the 2026-27 Gujarat school calendar, Gemini's price).
- **ChatGPT** wrote a second development plan, compared with Claude Code's and merged.
- **Gemini 3.5 Flash-Lite, inside the product**, writes a one-line opening for each answer, Hindi translations, and reads questions typed in English letters. It never computes a number; a checker rejects any number it writes that is not in the data.
- **Vishv decided**: what to build first, every design choice that changed the answers, the Gujarati wording, and the assumptions emailed to the reviewer.
- **Where the AI was wrong**: 56 times, listed at the end with how each was caught.

## Tools

- **Claude Code** (desktop app, Claude Opus 5.5): reading the brief, research, design discussion, writing code and docs, running checks.
- **Firecrawl** (web search and scraping, called from Claude Code): research on VSK, Gunotsav, CRC role, Gujarat school calendar, causes of low learning.
- **Claude app** (phone, then linked to the PC; Claude Opus 5.5): the UI polish pass, reading the live site through Firecrawl.
- **ChatGPT**: generated a second development plan from the brief, used as a comparison against the Claude Code plan.
- **Gemini API** (gemini-3.5-flash-lite, free tier): inside the product, for the opening line, Hindi, and reading questions the rules cannot place.
- **Remotion** (with Remotion's official agent skills from GitHub) and **Kokoro** (an open-source voice that runs on the laptop): the demo video, built by Claude Code around real recordings of the live app (D-036).
